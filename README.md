# DermaAI

DermaAI is an AI-based skin disease detection web application built using React, FastAPI, MongoDB, and Machine Learning.

## Project Status

The project is currently under development.

## Planned Features

- User authentication
- Image upload
- Webcam capture
- AI-based skin condition prediction
- Confidence score
- Scan history
- PDF report generation
- Deployment

## Technology Stack

### Frontend

- React
- Vite
- Tailwind CSS

### Backend

- FastAPI
- Python
- MongoDB

### Machine Learning

- PyTorch
- Transfer Learning
